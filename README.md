# Userbot-автоответчик (Pyrogram)

Бот работает от имени вашего Telegram-аккаунта. Каждому, кто впервые напишет вам в личку:

1. ждёт 1–2 минуты, отмечает сообщение прочитанным;
2. показывает «печатает…» и пишет, что вакансия уже не актуальна;
3. примерно через 5 минут снова «печатает» и по-дружески советует поискать в канале (ссылка из `.env`).

Фразы каждый раз выбираются случайно из нескольких вариантов, время «печати» зависит от длины текста.
Бот полностью асинхронный: каждый диалог идёт отдельной задачей, поэтому он ведёт сколько угодно людей одновременно, и паузы одного не задерживают других.

Каждому человеку бот отвечает **только один раз**: ID хранятся в SQLite-базе `users.db` вместе с этапом диалога. После перезапуска повторов не будет, а если бот остановили посреди диалога, при следующем запуске он допишет недостающее сообщение.
Боты, группы, каналы и ваши собственные сообщения игнорируются.

## Установка

Нужен Python 3.9+.

```bash
cd userbot
python -m venv venv
# Windows: venv\Scripts\activate
source venv/bin/activate
pip install -r requirements.txt
```

> Если `tgcrypto` не ставится (нет компилятора), удалите эту строку из `requirements.txt`, бот будет работать и без неё, просто чуть медленнее.
> Если на новом Python возникают ошибки с `pyrogram`, замените его на поддерживаемый форк: `pip install kurigram` (код менять не нужно).

## Настройка

1. Зайдите на https://my.telegram.org → **API development tools**, создайте приложение, скопируйте `api_id` и `api_hash`.
2. Скопируйте `.env.example` в `.env` и впишите свои значения:

```
API_ID=1234567
API_HASH=ваш_api_hash
SESSION_NAME=my_account
CHANNEL_LINK=https://t.me/+fpeV0o0QOIo4MTli
```

## Запуск

```bash
python bot.py
```

При первом запуске Pyrogram попросит номер телефона и код из Telegram (и пароль 2FA, если включён). После этого рядом появится файл `my_account.session`, и вход больше не понадобится. **Никому не передавайте этот файл**, это полный доступ к аккаунту.

Бот должен работать постоянно, иначе он не увидит новые сообщения. Для круглосуточной работы запустите его на VPS (например, через `screen`, `tmux` или systemd).

## Запуск на сервере

На сервере нельзя удобно ввести код из Telegram, поэтому вход делается один раз у себя на компьютере:

```bash
pip install -r requirements.txt
python login.py
```

Скрипт выведет `SESSION_STRING=...`. Её нужно вставить в `.env` на сервере (рядом с `API_ID` и `API_HASH`). Эта строка даёт полный доступ к аккаунту, не публикуйте её и не коммитьте.

### Вход прямо на сервере (Docker)

Если терминал сервера открыт, проще войти интерактивно, одним запуском:

```bash
docker compose run --rm userbot python bot.py   # ввести номер, код и пароль 2FA
# после «Бот запущен» нажать Ctrl+C, сессия сохранится в data/
docker compose up -d
```

`server_login.py` (вход в два шага) может не сработать: Telegram иногда сразу считает такой код истёкшим.

### Вариант 1: Docker (проще всего)

```bash
git clone <ссылка на репозиторий> /opt/userbot && cd /opt/userbot
cp .env.example .env && nano .env      # вписать API_ID, API_HASH, SESSION_STRING
docker compose up -d --build
docker compose logs -f                 # посмотреть логи
```

База `users.db` хранится в папке `data/` и не пропадает при перезапуске контейнера.

### Вариант 2: systemd

```bash
git clone <ссылка на репозиторий> /opt/userbot && cd /opt/userbot
python3 -m venv venv && venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env
sudo cp userbot.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now userbot
journalctl -u userbot -f               # логи
```

Обновление: `git pull`, затем `docker compose up -d --build` или `sudo systemctl restart userbot`.

## Как изменить поведение

Всё в начале `bot.py`:

- `FIRST_MESSAGES` и `SECOND_MESSAGES` — варианты фраз, можно добавлять свои;
- `FIRST_DELAY` — пауза перед первым ответом (сейчас 60–120 сек);
- `SECOND_DELAY` — пауза перед советом с каналом (сейчас 270–330 сек).

Чтобы бот снова ответил человеку, удалите его из базы (при остановленном боте):

```bash
sqlite3 users.db "DELETE FROM users WHERE user_id = 123456789;"
```

## Важно

Telegram может ограничить аккаунт, если на него много жалоб на спам. Бот отвечает только тем, кто написал сам, и только один раз, но лучше не использовать для этого основной личный аккаунт.
